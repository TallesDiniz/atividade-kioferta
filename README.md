# Perguntas A1 a A6

### A1. O que é o framework e qual abordagem ele segue?
**R:** Tailwind CSS, ele é utility-first, sendo assim não é necessário criar classes para uma determinada linha de código — a estilização é feita diretamente pelo HTML.

### A2. Como você incluiu o framework na página?
**R:** Realizando a instalação via npm, depois importando como plugin no vite.config e, por fim, importando no style.css.

### A3. Cite três benefícios que você percebeu ao usar, não apenas os que o site do framework anuncia.
**R:** Legibilidade, manutenção fácil e consistência visual — como os espaçamentos e tamanhos de fonte seguem uma escala fixa, fica mais difícil criar valores desalinhados entre uma tela e outra sem perceber.

### A4. Cite duas limitações ou desvantagens.
**R:** O arquivo HTML fica mais poluído e a curva de aprendizado é um pouco complexa, principalmente as nomenclaturas como gap-6 e text-lg.

### A5. Abra o CSS do framework (ou inspecione um elemento no DevTools F12). Ele estiliza usando classes ou IDs? Por que você acha que frameworks preferem um dos dois?
**R:** O Tailwind CSS estiliza por meio de classes. Utilizando classes ao invés de ID, você mantém uma melhor reutilização no seu código.
